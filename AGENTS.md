# Project Instructions & Guidelines

## Design Policy for Personal Projects

- **Independent Visual Identity**: Each new personal project created inside `projects/<project-name>/` must have its own unique, fresh visual design, color palette, typography, and styling language.
- **No Inheritance from Hub**: Under no circumstances should a project adapt, borrow, or copy the aesthetic or theme of the main project hub page (`index.html` / `style.css`).
- **Autonomous Scaffolding**: Keep each project modular and completely self-contained with its own layout and styling.
